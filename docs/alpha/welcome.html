Welcome to the AIQ private alpha

Thanks for trying AIQ. This page is everything you need. It takes two minutes to read.

What AIQ is

AIQ is a private coach for how you work with AI agents such as GitHub Copilot. It is not a report card and not a diagnostics tool. It helps you build better habits, one small step at a time.

AIQ places each finished task on a five-step ladder: Assisted, Directed, Delegated, Orchestrated, Factory. When it sees an easy next step for the kind of task you just did, it shows one short tip in your tool, marked AIQ tip:. The goal is that, over a few weeks, the tasks you repeat move up a step. Only you see any of this. There is no manager view, no team view and no AIQ server.

Install (Windows, about two minutes, no admin rights)

  1. Open <https://github.com/imransargusingh/AIQ/releases/latest>, download the

aiq-<version>-windows-x64.zip file listed there, and unzip it anywhere.

  1. Double-click install.cmd in that folder. A window shows each step and waits for you to close it.

If you prefer a terminal, run this in a normal PowerShell window in that folder:

   powershell -ExecutionPolicy Bypass -File .\install.ps1

Typing .\install.ps1 on its own does not work: Windows refuses it because the script is not signed.

That is all. AIQ connects to the AI tools it finds, lists every file it changed, reads your past sessions on this computer, turns on judging (below) and opens AIQ home. There is nothing to set up.

The program files are not code-signed yet, so Windows or your company's device rules may warn you. Check your employer's rules before installing on a work computer.

To undo it fully: aiq uninstall --all takes AIQ out of every tool and removes its PATH entry and Start menu shortcut. Your AIQ data stays until you also run aiq forget --all.

What to expect in the first days

  • Day one is mostly quiet. AIQ reads your past sessions and judges your finished tasks in the

background. You may see no tips at all at first. That is normal, not a fault.

  • Tips are rare on purpose. At most 5 a day, only when AIQ is confident, and never in the middle of

your work. It shows a tip when the agent stops, or on the Copilot CLI status line.

  • Some tips will be wrong. This is early software. If a tip or a judgment doesn't fit how you work,

press This doesn't fit in AIQ home. AIQ also checks itself and pauses a kind of tip when its own accuracy drops.

  • AIQ updates itself when there is a new version, while AIQ home is closed. To update straight

away, press Update now in AIQ home. Your data and settings stay.

  • Need a break? aiq pause, then aiq resume when you're ready.
  • Progress takes weeks. AIQ needs several tasks of the same kind before it can show one moving up

a step.

Feedback and help

Tell us anything: what helped, what annoyed you, what was wrong. Contact imrans.

If something breaks, run aiq status --report and send the file it makes. It has counts, timings and error codes. It has no prompt text, and folders appear as folder-1, folder-2. Nothing is sent unless you send it.

The code is public, so you can check anything on this page or open an issue: <https://github.com/imransargusingh/AIQ>.
