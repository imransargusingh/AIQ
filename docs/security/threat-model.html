Threat Model

System-level pass written during `/define-architecture` (no component designs exist yet). Once designs exist, section 2 is regenerated with `python3 docs/ai-forward-pack/scripts/docs-graph.py rollup --heading "Adversarial analysis (STRIDE-lite)" --type design`.

Assets: prompts and agent transcripts (may contain code, secrets, customer data); code excerpts; derived signals and coaching history (reveal how someone works); feedback; the store key; pack signing keys. Attackers considered: other software running as the same or another OS user; a malicious or compromised pack; a network attacker; someone holding a lost or stolen laptop; a curious colleague or manager (social, not technical: AIQ must give them nothing to ask for).
