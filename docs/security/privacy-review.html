3. Data-subject rights paths

Access: capture log and AIQ home. Export: Settings → Export. Delete: one item, older-than, all. Rectify: feedback on guidance (rung placement itself is not edited, per the rung-model spec). Object: pause per surface, turn judging off, uninstall removes the store and keychain entries.

4. Telemetry alignment

No remote telemetry. Local health counters only.

5. Transfers and processors

The person's own AI provider (Anthropic via their API key; GitHub Copilot via VS Code) for judge calls only. AIQ operates no processor that sees user data. The pack CDN receives no identifiers.
