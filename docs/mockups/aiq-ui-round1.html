As built and checked on Imran's laptop: Claude Code adds the dim "Stop says:" prefix and draws hook text dim; AIQ adds one bold yellow "AIQ tip:" label (the only colour code). Colour adds emphasis, never meaning.

Fallback when colour is off (NO_COLOR set, or a terminal that drops it): a blank line, an upper-case AIQ TIP label and a ">>" gutter keep it visible without colour. Screen readers hear "greater than" on each line, which is the cost.

AIQ · Set up

Your coach, on your computer only

AIQ watches how you work with AI agents and suggests one small change at a time, so agents finish more of your work with less redoing.

Only you see it

No manager or team view exists. Nothing about you leaves this computer unless you share it.

About the task, not you

Tips are about the kind of work you are doing, never a score of you.

You control the data

Pause any time. Delete one item, anything older than a date, or everything.

Choose the tools AIQ watches

AIQ reads your prompts and when each turn ends. It never slows your tools: if AIQ is down, they behave as before.

Connect your Anthropic API key

AIQ asks Claude to read a finished task and say how much the agent did. It uses your own key, so the same provider that already saw the work reads it again. Nothing goes to AIQ.

Stored in Windows Credential Manager. Only your user account can read it. Anthropic says this key is not valid. Check you copied all of it, or make a new one in the Anthropic Console.
Using a work account? Your organisation's policies apply to these calls, including any logging and retention it has set. Judging uses your quota, up to a daily budget you set below.
Without a key, tips still work. Rung views wait.

How many tips a day?

At most one tip per session, shown when the agent pauses. Change this any time in Settings.

This only sets where AIQ starts. It adjusts to the work it sees you do.

One thing to know before you start

Your history lives only on this computer. AIQ keeps no copy and has no backup in this version.

If you lose this computer or reinstall Windows, your AIQ history is gone. Your tools and work are not affected.
