9. Defect classes registered

None new in AIQ code. One pack defect found while running the skill: render-markdown.py (V19) writes <name>.html beside <name>.md, so running it on the mockup hub docs/mockups/aiq-home.md overwrote the mockup docs/mockups/aiq-home.html (recovered from a working copy). Rule here: never render a mockup hub .md; its .html sibling is the mockup. This should go upstream to AI-Forward as a guard (skip when the sibling .html is not a render).
