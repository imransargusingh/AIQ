## Definition of done (exit gate)
- [ ] Every task traces to a spec statement; boundary set covered, not just the happy path.
- [ ] **Instrumented by default** — the operator questions (how long, how often, how much, which path, did it fail) each have a **named emitting source on the normal path**; the emission was **observed at least once on a real run with the value read back**; cost axes (latency, spend/tokens, volume, failure rate) are covered, not just correctness; every measurement path **degrades to "not recorded" rather than to a wrong number**; anything still unmeasurable is recorded as a **named instrumentation gap with what it prevents** (`instrumentation-over-inference.md` IO1–IO12). *A feature is not done until its behaviour is measurable without a flag, a re-run, or a debugger.*
- [ ] **Change-surface list ticked off** — store → model → service → projection/wire → client type → UI → compute reader; every new/changed field has a traced **writer** and a traced **compute reader**; no declared-but-unwritten shape shipped; the new surface is **reachable** (`end-to-end-integrity.md` E7–E10).
- [ ] **Surface and cross-surface proof**: at least one test through the **real composition root to the rendered surface**, and a **cross-surface consistency** test wherever a quantity appears on more than one surface (E11–E12). Gates verified to execute their contents; consequential commands had their state read back (E13–E14).
- [ ] **Data model honoured** (`domain-and-data-modelling.md`): the design's grain, additivity and history rules implemented as written; append-only/interval invariants enforced *and* tested (incl. a test that attempts a forbidden update); no quantity given a second home; any migration expand-migrate-contract with a non-guessing backfill, applied by the deployer, with the down path exercised.
- [ ] **Defect classes registered** (`continuous-improvement.md` CI1): every defect introduced, assumption falsified, or correction received is captured as a **class** with its control in `docs/lessons/defect-classes.md`, the control observed failing on the un-fixed code.
- [ ] **Failure-mode analysis carried through**: every failure mode from the design (plus those the implementation introduced) is handled in code and proven by a negative/error-path test, or its acceptance is recorded with rationale + residual risk.
- [ ] Every test invokes the focal behavior, has a meaningful assertion, is deterministic, and was **seen red before green** (or justified via mutation/fault injection).
- [ ] **All** triggered Testing Strategy directives applied as a union (mandatory — none dropped without a recorded deviation); D0 hygiene on every test; mutation/eval thresholds wired or recorded as residual risk (Test Architect hard veto).
- [ ] **Instrumented to the Observability Standard**: a span per unit of work, structured logs carrying trace context, stable error codes on failures, RFC 9457 problem responses on HTTP errors, no secrets/PII in telemetry (O1–O13); load-bearing telemetry covered by a test (SRE).
- [ ] Style Guide / LOA idiom conformance; patterns named in comments.
- [ ] **Ladder climbed per task** (smallest correct rung; no gratuitous dependency); bounded shortcuts carry inline `simplify:` markers (ceiling + trigger); the Simplifier's delete-list pass ran at the gate (`solution-selection-ladder.md` L1/L5/L9).
- [ ] **Ceremony matched the tier** (L7): T0 = code-first + one runnable check (heavy artifacts not required); T1/T2 = full discipline, artifacts not thinned.
- [ ] Test Architect's hard veto cleared; pre-merge review passed; author did not self-certify.
- [ ] **Proof Pack** complete (Oracle, Red-observed, Confidence filled); residual risk stated; deviations recorded.
- [ ] **Status table emitted**: completed / remaining / best next action.
- [ ] **UI built to the system (if the component has an interface)**: tokens only (no arbitrary values); **every specified state implemented incl. empty/loading/error**; platform HIG + responsive/adaptive behavior; motion with reduced-motion; real in-voice copy; **WCAG 2.2 AA and the performance budget met and proven red-first** (keyboard path, contrast/labeling, empty/error render, perf threshold); AI-UI HAX/Shape-of-AI patterns made real with tests (UI Standard U20; UX & Accessibility lens's veto). **On an expert/quantitative surface**, **`technical-ui-design.md`** (TQ1–TQ12) is triggered: build and prove the perceptually-uniform colormap (never jet), tabular unit-bearing numerics at declared precision, uncertainty-first rendering, provenance and reactive recompute with visible staleness.
- [ ] **Built to the design-language doc** (`DESIGN.md`, U3a): tokens referenced (no raw values); `scripts/design-lint.py` clean.
- [ ] **UI craft gate run against the built source** (`ui-craft-detection.md` CD8.3): `scripts/ui-craft-gate.py <built-source> --gate [--a11y-obligation]` — the deterministic 59-rule detector reading `DESIGN.md` natively, which is what actually enforces U3/U20 ("tokens, never raw values") *outward* against the implementation rather than only inward against the token file (CD5). It is written **red-first** like any other control: confirm the rule fires on the un-fixed code before claiming it works (CI6). Confirm it **scanned a non-empty corpus** and **reported its own status** — a gate that matched no files, or whose exit code was swallowed by a chained shell block, is a success-shaped failure (CD9, E13–E14). Any suppression carries a real reason; a standing one is a recorded deviation (CD16).
- [ ] **Generated assets (if any) committed, not linked** (`ui-visual-assets.md` VA4, VA12–VA14): downloaded, optimized, referenced by relative path, with manifest entry, **alt text** and disclosure; performance budget met; no real likeness or personal data ever uploaded (VA9).
