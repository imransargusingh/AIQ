Five rungs, from asking to handing over

AIQ places each task you finish on this ladder. Most people work on several rungs. The goal is that the tasks you repeat move up over a few weeks.

  1. 1AssistedYou ask AI for answers or pieces, and you do the work.
  2. 2DirectedYou give the agent a clear goal, the context and the limits, and check what it gives you.
  3. 3DelegatedYou hand the agent a whole outcome with done criteria. It makes the changes; you review.
  4. 4OrchestratedA written spec drives several agents or steps, with automated checks between them.
  5. 5FactoryA saved, versioned workflow runs the work, for you and for others.

How it works

Nothing to set up and nothing new to learn. You keep working in your own tools.

1 · Install

AIQ connects to your tools

Copilot CLI, VS Code and Claude Code. It lists every file it changed, and one command undoes it all.

2 · Work as usual

AIQ analyzes finished tasks

In the background, it learns the kinds of task you do and which rung each one is on.

3 · Try one tip

A short tip, when it helps

At most 5 a day, never in the middle of your work. AIQ home has a starter prompt for it you can copy.

Private by design

Only you see your results. There is no manager view, no team view and no AIQ server.

  • Your prompts stay on your computer.AIQ keeps them in your user folder and sends no telemetry.
  • Analysis uses your own sign-in.Each finished task goes to the same AI tool that did it, with secrets removed. Never your files or diffs. On Copilot it uses premium requests.
  • You can switch it off.Analysis and the daily update check each have their own off switch in Settings.

Install

  1. Download the aiq-…-windows-x64.zip from the latest release and unzip it.
  2. Double-click install.cmd.

AIQ updates itself. To undo fully, run aiq uninstall --all, then aiq forget --all to delete your AIQ data.

This is an early alpha

Thanks for trying it early. A few things to know first.

Day one is quiet

AIQ needs some finished tasks before it shows a tip. No tips at first is normal.

Some tips won't fit

Press This doesn't fit in AIQ home. AIQ also pauses a kind of tip on its own when its accuracy drops.

Windows may warn you

The files are not code-signed yet. On a work computer, check your employer's rules first.
